# Day 2: Groq Chatbot and Python Fundamentals

This Google Colab notebook builds a simple conversational assistant for **Sweet Crumbs Home Bakery** using Groq’s API and the OpenAI Python client.

Along the way, it demonstrates Python dictionaries, JSON serialization, functions, decorators, conversation history, and basic API error handling.

## What the notebook does

- Connects to Groq using the OpenAI-compatible API.
- Sends messages to the `openai/gpt-oss-120b` model.
- Uses system instructions to guide the bakery assistant’s tone and responses.
- Provides menu prices and bakery information to the assistant.
- Runs an interactive chat loop that remembers recent messages.
- Handles rate-limit and connection errors with friendly messages.
- Demonstrates Python concepts with menu and order examples.

## Bakery information in the notebook

| Item | Price |
| --- | ---: |
| Plum cake | ₹500 |
| Chocolate cake | ₹650 |
| Cupcake | ₹80 |

The assistant’s instructions also state that orders need 24 hours’ notice, all cakes have eggless versions, and it should not promise delivery times.

## Requirements

- A Google account with access to Google Colab
- A Groq API key
- Internet access while running the notebook

## Setup and usage

1. Open `task2.ipynb` in Google Colab.
2. In Colab, open **Secrets** and add a secret named `GROQ_API_KEY`.
3. Paste your Groq API key as the secret value and enable notebook access to it.
4. Run the notebook cells in order. The first cell installs the OpenAI Python package.
5. When the interactive chat starts, enter messages at the `You:` prompt.
6. Enter `bye`, `exit`, or `quit` to end the chat.

The notebook connects to Groq through its OpenAI-compatible API endpoint:

```python
client = OpenAI(
    api_key=userdata.get("GROQ_API_KEY"),
    base_url="https://api.groq.com/openai/v1",
)
```

## Python concepts demonstrated

- **Dictionaries:** Store menu prices and order details.
- **Safe dictionary lookup:** Use `.get()` to provide a fallback for missing menu items.
- **JSON:** Convert a Python dictionary to a JSON string and back.
- **Functions:** Calculate the total price for a menu item and quantity.
- **Decorators:** Log calls to the `get_price` function.
- **Conversation history:** Keep recent user and assistant messages for context.
- **Exception handling:** Respond to API rate-limit and connection errors.

## Notes and limitations

- The menu and prices are sample data defined in the notebook.
- `get_price()` demonstrates local price calculation; the chat loop does not call it as an integrated tool.
- Conversation history is kept in memory for the current notebook session and is not saved as a customer order.
- The assistant’s replies are generated by an AI model and should be checked against the bakery’s actual policies and availability.
- This notebook uses Google Colab’s `google.colab.userdata` and is not configured as a standalone Python program.

## Security

Keep your API key in Colab Secrets or another secure secret manager. Do not paste it directly into the notebook or commit it to GitHub.
